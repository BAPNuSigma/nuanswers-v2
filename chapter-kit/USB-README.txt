WHAT THIS IS
An AI teaching assistant for accounting & finance students.
It guides students to answers Socratically (never gives the
answer away), reads their course materials, and shows
professors exactly where the class is struggling.

Built by students, for students — and now for your
chapter too.

WHAT'S ON THIS USB
  1. The complete source code (the nuanswers-v2 folder)
  2. START-HERE.md .............. AI-guided setup (easiest!)
  3. chapter-kit/README.md ...... manual setup guide (~1 hour)
  4. chapter-kit/CUSTOMIZE.md ... adapt it to your school

START HERE (THE EASY WAY)
  1. Copy the nuanswers-v2 folder from this USB to your
     computer.
  2. Install Claude Code: claude.com/claude-code
  3. Open Claude Code in that folder and type:
       Read START-HERE.md and set up NuAnswers
       for my chapter.
  4. Answer its questions. Claude does the technical work
     and walks you through the rest, one step at a time.

Prefer to do it by hand? chapter-kit/README.md has the
same setup as numbered steps. Either way you'll need free
GitHub, Vercel, and Supabase accounts plus an OpenAI key
(~$10 to start).

See it live: https://nuanswers.org

Questions? Reach out to the BAP Nu Sigma chapter at FDU.
